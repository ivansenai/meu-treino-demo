🏋️ Meu Treino — Projeto Android

Aplicativo de acompanhamento de treinos com integração entre smartphone Android e smartwatch Wear OS.

📱 Sobre o projeto

O Meu Treino é um projeto autoral desenvolvido para facilitar o registro de atividades físicas e o acompanhamento dos dados do treino.

O projeto explora o desenvolvimento Android com Kotlin e a comunicação entre dispositivos móveis e relógios inteligentes.

🚀 Funcionalidades desenvolvidas

- Registro e histórico de exercícios.
- Cronômetro para acompanhamento dos exercícios.
- Monitoramento da frequência cardíaca (BPM).
- Comunicação entre smartphone e smartwatch.
- Sincronização de dados com Wear OS.
- Monitoramento de BPM mesmo com a tela do relógio em standby.
- Automação de builds utilizando GitHub Actions.

🛠️ Tecnologias utilizadas

- Kotlin
- Android
- Wear OS
- Bluetooth e comunicação entre dispositivos
- Git e GitHub
- GitHub Actions

🎯 Objetivo

Desenvolver uma solução mobile integrada, explorar tecnologias vestíveis e aprimorar conhecimentos em desenvolvimento de software.
